# JARVIS — персональный локальный ИИ-ассистент для Windows

Локальный ассистент на базе Qwen (через Ollama) с инструментальной архитектурой:
модель сама выбирает и комбинирует инструменты, опасные действия требуют
подтверждения, всё сохраняется в локальной SQLite-памяти. Без платных API и облака.

> **Статус:** Phase 1–2 готовы, Phase 3 — основное готово, Phase 4 — начата: голосовой ассистент,
> приложение с установщиком, запуск программ, сайты и YouTube. Дальше — файлы, окна, Office, почта
> (см. [docs/ROADMAP.md](docs/ROADMAP.md)).

## Установка — как обычная программа (рекомендуется)

1. Откройте страницу **Releases** репозитория → «JARVIS (последняя сборка)» → скачайте
   `JARVIS-Setup-x.y.z.exe`.
2. Запустите установщик: «Далее» → «Установить». Права администратора не нужны.
   Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
3. При первом запуске откроется **мастер настройки**: нажмите «Установить всё автоматически».
   Он скачает и запустит официальный установщик Ollama (нажмите в нём «Install»), затем скачает
   языковую модель (~5 ГБ), голос и распознавание речи. Окно можно оставить — оно не закроется.
4. Готово: скажите «**Джарвис**» или нажмите «🎙 Слушать».

Окно сворачивается в трей (значок у часов). Ctrl+Alt+J — показать окно и начать слушать.

## Требования

| | Минимум | Целевая конфигурация |
|---|---|---|
| ОС | Windows 10/11 x64 | Windows 11 |
| Python | 3.11 | **3.12** |
| GPU | любой / CPU (медленно) | RTX 3060 12 GB |
| RAM | 16 GB | 32 GB |
| Диск | ~10 GB (модель 5.2 GB) | SSD NVMe |
| [Ollama](https://ollama.com/download/windows) | 0.9+ (`think`, стриминг tool calls) | последняя |

## Установка для разработчика (из исходников)

```bat
git clone <repo> jarvis
cd jarvis
jarvis.bat
```

Первый запуск `jarvis.bat` вызывает `scripts\install.ps1`, который:
1. находит Python 3.12/3.11 (предложит установить через `winget`, если нет);
2. создаёт `.venv` и ставит зависимости;
3. проверяет Ollama (предложит `winget install Ollama.Ollama`) и запускает сервер;
4. скачивает модель `qwen3:8b` (~5.2 GB);
5. запускает диагностику `jarvis doctor`.

Ручная установка:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\pip install -e .
winget install Ollama.Ollama
.venv\Scripts\python -m jarvis setup      # ollama pull qwen3:8b
.venv\Scripts\python -m jarvis doctor
```

## Что JARVIS умеет на компьютере

Просто скажите или напишите — JARVIS сам выберет нужное действие:

* «Открой Chrome / Word / Telegram / калькулятор» · «Закрой хром»
* «Открой YouTube и включи лофи музыку» — найдёт видео и сразу включит его
* «Открой ютуб в хроме и найди обзоры RTX 3060» — покажет результаты поиска
* «Открой сайт vk.com» · «Найди в гугле рецепт борща»
* «Пауза» · «Следующий трек» · «Сделай громче» · «Выключи звук»
* «Открой настройки звука / Bluetooth / обновления Windows»
* «Какие программы сейчас запущены?» · «Сколько свободно места на диске?»

Системные процессы, антивирус и сам JARVIS закрыть нельзя. Опасные действия — только с вашего подтверждения.

## Голос

* «Джарвис» → «Слушаю вас» → команда. Можно сразу: «Джарвис, который час?».
* Несколько команд подряд без повторного «Джарвис». «Всё, спасибо» — завершить; после
  15 секунд тишины (настраивается: 5/10/15/20/30/60) JARVIS засыпает сам.
* **Выбор голоса:** раздел «Голос» в приложении (кнопка «▶ Прослушать») или
  `jarvis-cli voices` → `jarvis-cli voices --set 2`. Русские: Дмитрий, Денис, Руслан, Ирина;
  английский голос для английского текста (по умолчанию британский Alan). Скорость и громкость
  настраиваются. Можно добавить любой голос Piper (файлы `.onnx` + `.onnx.json`) в папку голосов.
* Ключевое слово меняется в разделе «Голос» (например, «пятница»).

## Запуск из консоли

```bat
jarvis.bat                    :: приложение (окно)
jarvis.bat voice              :: голосовой режим в консоли
jarvis.bat chat               :: текстовый чат в консоли
jarvis.bat chat --continue    :: продолжить последний разговор
jarvis.bat ask "сколько будет 2^32?"
jarvis.bat doctor             :: диагностика: Python, GPU/VRAM, Ollama, модель, БД
jarvis.bat setup --model qwen2.5:7b-instruct
jarvis.bat config             :: пути и действующие настройки
```

В чате: `/new`, `/history`, `/open <id>`, `/tools`, `/facts`, `/audit`, `/model`,
`/help`, `/exit`. **Ctrl+C во время ответа** останавливает текущую задачу
(генерация прерывается сразу, соединение с моделью закрывается).
При выходе модель выгружается из видеопамяти.

## Настройки

Файл `%APPDATA%\JARVIS\settings.yaml` хранит только изменённые значения; всё
остальное — встроенные умолчания, подобранные под RTX 3060 12 GB.
Пример со всеми ключами: [config/settings.example.yaml](config/settings.example.yaml).

| Что | Где |
|---|---|
| Настройки | `%APPDATA%\JARVIS\settings.yaml` |
| База (разговоры, память, журнал) | `%LOCALAPPDATA%\JARVIS\data\jarvis.db` |
| Логи | `%LOCALAPPDATA%\JARVIS\logs\jarvis.log` |
| Портативный режим | `jarvis.bat --home D:\JarvisData` или переменная `JARVIS_HOME` |

Рекомендуемые переменные окружения **сервера Ollama** (снижают VRAM под контекст):
`OLLAMA_FLASH_ATTENTION=1`, `OLLAMA_KV_CACHE_TYPE=q8_0` — задаются в
«Переменные среды» Windows, затем перезапуск Ollama.
