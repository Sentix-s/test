# Отчёт: Phase 1

## Реализовано

- **Структура проекта** — модульные пакеты `core, settings, ai, tools, security, memory, cli` + заготовки
  пакетов следующих фаз (только docstring, без фиктивного кода).
- **AI Engine** — `OllamaClient`: версия, список/загруженные модели, загрузка и **выгрузка из VRAM**,
  скачивание с прогрессом, стриминговый чат с нативными `tool_calls`, `think`, `keep_alive`, опциями,
  немедленной отменой; понятные ошибки («Ollama не отвечает…», «модель не установлена…»).
- **Агентный цикл** — модель сама выбирает инструменты, многошаговые цепочки, лимит шагов с итоговым
  ответом, ошибки инструментов возвращаются модели, распознавание текстовых `<tool_call>` Qwen,
  фильтрация `<think>`.
- **Инструменты** — декоратор `@tool` с автогенерацией JSON-схем и мягким приведением типов;
  встроенные: `get_datetime`, `get_system_info` (CPU/RAM/диски/GPU/VRAM/температура через nvidia-smi),
  `calculate` (безопасный AST-калькулятор), `remember_fact`, `recall_facts`, `forget_fact`.
- **Безопасность** — уровни SAFE/MODERATE/DANGEROUS, подтверждение опасных действий, отказ без
  интерактивного пользователя, блок-лист, журнал всех решений и вызовов (`/audit`).
- **Память** — SQLite (WAL, миграции): разговоры с историей, факты (подставляются в промпт), журнал.
- **Ядро** — `JarvisApp` с состояниями OFF/STARTING/READY/BUSY/STOPPING/ERROR, выбор модели с
  fallback, прогрев при запуске, выгрузка при выключении, `EventBus` для будущего GUI.
- **CLI** — `chat` (стриминг, Ctrl+C = стоп задачи, подтверждения, команды), `ask`, `doctor`, `setup`, `config`.
- **Установка** — `jarvis.bat` + `scripts/install.ps1` (Python, venv, Ollama через winget, модель, диагностика).

## Проверено

- 60 автотестов (`pytest`), проходят на Python 3.11 и 3.12; пакет ставится через `pip install -e .`,
  команда `jarvis` работает.
- Тесты идут против **настоящего HTTP-сервера**, эмулирующего API Ollama (NDJSON-стриминг, chunked,
  tool_calls, keep_alive, pull), и запускают **реальный CLI-процесс**: многошаговые вызовы инструментов,
  подтверждение/отказ, отмена посреди генерации, выгрузка модели при выходе, ошибки конфигурации,
  недоступный Ollama, fallback-модель, бюджет контекста, кириллица.
- Наличие колёс `win_amd64` для Python 3.12 проверено по PyPI для всех зависимостей фаз 1–7
  (PySide6, faster-whisper/ctranslate2, openWakeWord, onnxruntime, piper-tts, pywinauto, pywin32,
  Playwright, nvidia-ml-py, keyring, MSAL, python-docx/openpyxl/python-pptx, mss, PyInstaller).

## Не проверено / ограничения

- **Реальная модель Qwen не запускалась**: среда разработки — Linux-контейнер без GPU, доступ к
  ollama.com заблокирован. Качество tool calling у `qwen3:8b` нужно проверить на вашем ПК:
  `jarvis.bat ask "сколько будет 1234*5678 и какой сегодня день?"` — в выводе должны появиться
  строки `⚙ calculate(...)` и `⚙ get_datetime()`.
- **`install.ps1` и `jarvis.bat` не запускались** на Windows (синтаксис PowerShell тоже не удалось
  проверить в этой среде). Это первое, что стоит прогнать.
- Подсчёт контекста — по символам, а не токенам (приблизительно; точный подсчёт — Phase 7).
- Отмена операций (`undo`) — только поле в журнале; реальные откатываемые операции появятся с
  файловыми инструментами в Phase 4.
