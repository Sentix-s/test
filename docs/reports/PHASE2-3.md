# Отчёт: Phase 2 (голос) и основная часть Phase 3 (приложение, установщик)

## Исправлено по отзыву пользователя

- **«После скачивания окно закрылось».** Точную причину на вашем ПК установить нельзя (лог не сохранился),
  поэтому устранён сам класс проблемы: лаунчер больше никогда не закрывается молча — при ошибке
  показывает пути к логам и ждёт нажатия клавиши; установщик пишет `install.log`; незавершённая установка
  продолжается при следующем запуске (маркер установки); любая критическая ошибка пишется в лог с трассировкой.
  Дополнительно JARVIS теперь **сам запускает Ollama**, если она установлена, но не запущена.
- **Простая установка** — `JARVIS-Setup.exe` + мастер первого запуска (см. README).
- **Общение в приложении**, а не в терминале.

## Реализовано

**Голос (Phase 2)**
- Три стадии SLEEP → ACTIVE → SLEEP; несколько команд подряд; таймер тишины 5/10/15/20/30/60 с
  отсчитывается после окончания ответа и не срабатывает, пока пользователь говорит; «Всё, спасибо»;
  прощальная фраза.
- Ключевое слово: движок «любое слово» (Whisper по началу фразы + фонетическое сравнение «Джарвис/Жарвис/
  Jarvis/Джервис») и openWakeWord («Hey Jarvis»). «Джарвис, открой Word» одной фразой — сразу команда.
- Распознавание: faster-whisper, large-v3-turbo на GPU / small на CPU, автоматический откат на CPU, если
  CUDA-библиотеки недоступны; CUDA-библиотеки ставятся pip-пакетами только при наличии NVIDIA.
- Синтез: Piper, 4 русских и 5 английских голосов, отдельный голос для английского текста, скорость,
  громкость, свои голоса; озвучивание начинается с первого готового предложения.
- Защита от собственного голоса: микрофон заглушен от начала обработки до конца речи + 250 мс.
- Загрузка моделей: HuggingFace → зеркало hf-mirror.com → GitHub.

**Приложение (Phase 3)**
- Главная: анимированное ядро (цвет и скорость = состояние, кольцо = громкость микрофона), кнопка питания
  (полное вкл/выкл: модель выгружается из VRAM, микрофон закрывается), «Слушать», «Стоп», чат с потоковыми
  ответами и шагами инструментов, история разговоров, перетаскивание файлов.
- Разделы «Голос» (с прослушиванием), «Модели ИИ» (смена и скачивание), «Система» (автозапуск, журнал
  действий, подтверждения). Диалог подтверждения опасных действий.
- Трей с компактным анимированным окном, сворачивание в трей, Ctrl+Alt+J.
- Мастер первого запуска: Ollama (официальный установщик с подтверждением пользователя) → модель → голос.
- Установщик: PyInstaller + Inno Setup, без прав администратора, ярлыки, автозапуск, удаление.

## Проверено

- 116 тестов локально (Linux, Python 3.11) + CI на Windows и Linux (3.11/3.12).
- **На чистой Windows-машине в CI:** установка Ollama → `install.ps1` → реальная модель Qwen отвечает через
  `jarvis.bat`; все 9 голосов каталога доступны; синтез → распознавание настоящим Whisper.
- Реальные модели в тестах: Piper (русский/английский), WebRTC VAD на синтезированной речи, openWakeWord
  («Hey Jarvis» — 20/20 срабатываний, посторонние фразы — 0), полный голосовой цикл
  «аудио → VAD → ключевое слово → агент → Piper → динамик» с проверкой заглушения микрофона.
- Окно: автотесты в offscreen-режиме (питание, чат, подтверждения, настройки голоса, мастер);
  собранная программа проходит самопроверку на Linux; на Windows — в CI-задании `installer`.

## Найденные и исправленные проблемы

- Windows: при выключенной Ollama пользователь видел «превышено время ожидания» вместо «Ollama не запущена».
- PySide6 6.12.0 роняет интерпретатор на Python 3.11 → на 3.11 используется PySide6 < 6.12.
- «Дарвин» будил JARVIS; первая фраза ответа не озвучивалась отдельно; заголовок голосового разговора
  перезаписывался.
- Настоящий Whisper услышал «Джарвис» как «Жарвец» → Whisper теперь получает ключевое слово как подсказку
  (hotwords), плюс сравнение по согласным.
- Падение процесса при выходе (Linux, Python 3.12): фоновые потоки окна обращались к Qt во время
  завершения → приложение теперь дожидается их и закрывает окна, пока Qt жив.
- Установленная версия не содержала CUDA-библиотек → распознавание шло бы на процессоре; мастер теперь
  один раз скачивает официальные библиотеки NVIDIA (~1 ГБ) при наличии видеокарты NVIDIA.

## Ограничения

- Голос с настоящим микрофоном и динамиками не проверялся (в CI нет аудиоустройств) — нужна ваша проверка.
- Голое «Jarvis» без «Hey» в движке openWakeWord срабатывает нестабильно; для «Джарвис» используйте движок
  «любое слово» (по умолчанию).
- Установщик не подписан цифровой подписью → предупреждение SmartScreen.
- Пока нет: разделов Performance и Memory, панели текущих задач, перебивания JARVIS голосом (barge-in).
