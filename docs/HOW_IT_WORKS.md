# Как устроен JARVIS и как чинить проблемы самому

## Из чего он состоит

```
 Микрофон ──► [Ключевое слово] ──► [Распознавание речи] ──┐
                 «Джарвис»            Whisper (текст)       │
                                                            ▼
 Окно / чат ─────────────── текст ─────────────────► [Агент] ◄──► [Ollama + Qwen]
                                                        │           «мозг»: решает,
                                                        │            что ответить и
                                                        ▼            какой инструмент вызвать
                                               [Инструменты] — открыть программу, YouTube,
                                                        │        калькулятор, память, …
                                         [Проверка безопасности + журнал действий]
                                                        │
 Динамики ◄── [Синтез речи Piper] ◄──── ответ ──────────┘
```

| Часть | Что делает | Где работает |
|---|---|---|
| **Ollama** | Отдельная программа, которая держит языковую модель Qwen в видеопамяти и отвечает на запросы | Значок ламы в трее, адрес `127.0.0.1:11434` |
| **Qwen (qwen3:8b)** | «Мозг»: понимает просьбу, пишет ответ, решает вызвать инструмент | Внутри Ollama, на видеокарте |
| **Агент** | Цикл: отправить вопрос модели → если она просит инструмент, проверить разрешение и выполнить → вернуть результат модели → … → готовый ответ | Внутри JARVIS |
| **Инструменты** | Конкретные действия: `open_app`, `youtube_open`, `calculate`, `remember_fact`… Модель видит их список с описаниями | Внутри JARVIS |
| **Безопасность** | Обычные действия — сразу; опасные (удаление, отправка, установка) — только после вашего «Разрешить» | Журнал: раздел «Система» |
| **Ключевое слово** | Слушает микрофон, но *не* отправляет звук модели; реагирует только на «Джарвис» | Процессор |
| **Whisper** | Превращает вашу речь в текст | Видеокарта (или процессор) |
| **Piper** | Превращает ответ в голос | Процессор |
| **SQLite** | Разговоры, факты о вас, журнал действий | Файл `jarvis.db` |

**Пример «Открой YouTube и включи лофи»:** текст → агент отправляет его Qwen вместе со списком
инструментов → Qwen отвечает «вызови `youtube_open(query="лофи")`» → JARVIS проверяет разрешение,
ищет видео на YouTube, открывает его в браузере → результат возвращается Qwen → Qwen пишет
«Включил…» → ответ показывается и озвучивается.

Модели скачиваются один раз и потом работают без интернета: языковая модель — через Ollama,
голоса и Whisper — с сайта HuggingFace (если он недоступен — с зеркала).

## Где что лежит

| Что | Путь (вставьте в адресную строку Проводника) |
|---|---|
| **Логи — первое, что смотреть при ошибке** | `%LOCALAPPDATA%\JARVIS\logs\jarvis.log` |
| Настройки | `%APPDATA%\JARVIS\settings.yaml` |
| Разговоры и память | `%LOCALAPPDATA%\JARVIS\data\jarvis.db` |
| Голоса, Whisper, библиотеки CUDA | `%LOCALAPPDATA%\JARVIS\data\models\` и `...\data\cuda\` |
| Программа | `%LOCALAPPDATA%\Programs\JARVIS\` |
| Модели Ollama | `%USERPROFILE%\.ollama\models\` |

В разделе «Система» есть кнопка «Папка логов».

## Как разбирать проблемы

1. **Прочитать сообщение об ошибке** в чате — обычно в нём уже есть причина.
2. **Открыть `jarvis.log`** и пролистать в конец: там полная информация (строки `ERROR`, `Traceback`).
3. **Диагностика:** меню «Пуск» → «JARVIS — консоль», затем `jarvis-cli doctor` — проверит Python,
   видеокарту, Ollama, модель, базу.

| Симптом | Что сделать |
|---|---|
| «Ollama не отвечает» | Запустить Ollama из меню «Пуск» (JARVIS и сам пытается её запустить) |
| «Модель … не установлена» | Раздел «Модели ИИ» → скачать `qwen3:8b` |
| Голос не запускается, ошибка скачивания | Проверить интернет; удалить папку недокачанной модели в `data\models\whisper\` и включить JARVIS заново |
| JARVIS не слышит «Джарвис» | Раздел «Голос»: проверить микрофон; включить ускорение на видеокарте; сменить ключевое слово |
| Говорит, что не умеет / нет доступа | Значит, такого инструмента ещё нет — это не настройка, нужна новая версия |
| Медленно отвечает | В «Модели ИИ» посмотреть, сколько видеопамяти занято; закрыть игры |
| Хочу начать с чистого листа | Закрыть JARVIS, удалить `%APPDATA%\JARVIS\settings.yaml` (настройки) — разговоры при этом останутся |

Если не получается — пришлите разработчику последние 50 строк `jarvis.log` и скриншот: этого почти
всегда достаточно, чтобы найти причину.
